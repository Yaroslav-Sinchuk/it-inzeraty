# IT inzeráty

Študentský startup na predmet Databázové systémy (UPJŠ).
Databáza IT pracovných ponúk na Slovensku – pozície, firmy, platy a technológie.

**Stránka:** https://yaroslav-sinchuk.github.io/it-inzeraty/

## DBMS
Microsoft SQL Server

## Súbory
- `DDL.sql` – vytvorenie databázy a tabuľky
- `DML.sql` – vloženie dát
- `DDL3.sql` – tabuľky technológií a benefitov pre prepájanie s inzerátmi
- `DML3.sql` – vloženie dát do tabuliek technológií a benefitov
- `DQL.sql` – dopyty (úlohy a riešenia)
- `DQL2.sql` – funkcie a agregácia (úlohy a riešenia)
- `DQL3.sql` – prepájanie tabuliek (úlohy a riešenia)
- `index.html` – stránka startupu

Skripty spúšťajte v poradí: `DDL.sql`, `DML.sql`, `DDL3.sql`, `DML3.sql`, potom `DQL.sql`, `DQL2.sql`, `DQL3.sql`.
